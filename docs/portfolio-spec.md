# ポートフォリオサイト｜現状の決定事項

## 1. サイトの目的

このサイトは単なる「制作実績を並べたポートフォリオ」ではなく、Web制作の相談・依頼につなげるサービスサイトとして設計する。

### 主な目的

- Web制作会社・Webディレクターから案件相談・制作依頼を受ける
- 継続的にWeb制作を任せてもらえる関係を作る
- 中小企業などからの直接相談にもつなげる
- 「Webサイトを作れる人」ではなく「外部Web担当」として認知してもらう

---

## 2. ターゲット

### 第一ターゲット

- Web制作会社
- Webディレクター
- 制作会社の案件を担当する人

### 第二ターゲット

- Web担当者がいない中小企業
- Webサイト制作・改善・運用について相談したい企業

---

## 3. ポジショニング

目指す立ち位置は、

> 事業理解から、課題整理・設計・制作・運用まで伴走する外部Web担当

単なるコーダー・制作者としてではなく、

- 要件整理
- 課題整理
- サイト構成
- Webデザイン
- WordPress / Shopifyなどの実装
- 制作進行
- 公開後の運用・改善
- AIを活用した効率化

まで含めて相談できる存在として見せる。

# 7. ファーストビュー（FV）

## コピー

現時点で以下を使用する。

いっしょに考え、いっしょに、形にしていく。

事業理解から、設計・制作・運用まで伴走する
Webパートナーです。

---

## FVで伝えたいこと

「Webサイトを作ります」ではなく、

- 一緒に考える
- 一緒に形にする
- 事業を理解する
- 制作だけで終わらない
- 運用まで考える

という仕事のスタンスを最初に伝える。

---

## FVビジュアル

ブラウザのモックアップをメインビジュアルにはしない。大きなイラストも、FVの主役には置かない。

代わりに、**タイポグラフィを主役**にする（デザイン方針「案A：ひと言で伝える」を採用）。

- 大きな見出し（確定コピー）＋ キーフレーズに一筆のマーカー（アクセント色）
- 見出しの上に、切り替わる短い言葉（例：「Webの [相談 / 設計 / 制作 / 運用]、ぜんぶ となりで。」）で対応範囲と距離感を伝える
- 見出しの横に「仕事の進め方」5ステップの細いレール（"整理" を強調＝差別化ポイント）

イラストを使う場合は、FVではなく他セクション（自己紹介 など）で小さく使う程度にとどめる。

### ビジュアルの目的

「制作者が一方的に作る」のではなく、
「クライアントと一緒に考えて形にする」「渡したあと迷子にならない」
というブランドイメージを、言葉と“進め方の可視化”で伝える。

---

# 8. 提供価値

単純な制作スキルではなく、仕事の進め方そのものを価値として見せる。

特に伝えたい内容は、

- 着手前に全体を整理する
- 認識のズレを防ぐ
- 必要な情報や要件を整理する
- クライアントと一緒に考える
- 制作だけでなく運用まで考える
- AIなども活用して効率的に進める

という考え方。

### ユーザーに持ってもらいたい印象

「この人と仕事すると丁寧そう」

「制作を丸投げするだけではなく、一緒に考えてくれそう」

「案件を渡した後も、状況を整理しながら進めてくれそう」

という安心感を作る。

「実際に依頼したら、どういう流れで進むのか」

1. 相談
2. ヒアリング

単なる制作工程ではなく、

「制作前の整理・認識合わせを大切にしている」

# 13. FAQ

問い合わせ前に発生しやすい不安を解消する。

想定する質問例：

- どんな案件を依頼できますか？
- WordPress以外も対応できますか？
- 制作途中の案件でも相談できますか？
- 既存サイトの修正・改善だけでも依頼できますか？
- 保守・運用もお願いできますか？
- オンラインでの打ち合わせは可能ですか？
- 制作会社からの外注・協力案件にも対応できますか？
- NDA案件でも相談できますか？
- どの段階から相談すればいいですか？

FAQは単なる補足ではなく、

「依頼して大丈夫そう」

と思ってもらうための不安解消コンテンツとして扱う。

# 14. CTA

最終的な目的は問い合わせにつなげること。

CTAでは、

「制作を依頼してください」

だけではなく、

「まず相談してみる」

という心理的ハードルの低い導線を作る。

問い合わせ内容が具体的に決まっていない段階でも相談できることを伝える。

# 15. デザイン方針

全体として、

「適度に柔らかい」

方向性で決定。

硬すぎる制作会社サイトではなく、

- 相談しやすい
- 丁寧
- 親しみやすい
- 人柄が伝わる

デザインを目指す。

ただし、かわいさ・カジュアルさに寄りすぎず、

「Web制作を安心して任せられるプロフェッショナル感」

は残す。

---

# 16. 情報量

方向性は、

「広めだけど情報量も確保」

とする。

余白を十分に取りながらも、ポートフォリオとして必要な情報はしっかり掲載する。

情報を削りすぎて「雰囲気だけのサイト」にはしない。

---

# 17. ビジュアル・装飾

方向性は「**タイポグラフィと余白で品を出す（案A）＋ UI に少しだけ動き**」。
参考の空気感は TNGC Graphics（イラスト一点豪華・タイポで品・売り込みすぎない・事業として整って見える）。ただしポップさは抑え、実務・技術・「任せられそう」に寄せる。デザイン自体は複製しない。

主な手法:

- 日本語ゴシック（Zen Kaku Gothic New）。見出しは太さ 600 中心、広めの余白、サイズ跳躍は控えめ
- 英字のセクションラベル（`01 VALUE` など）を小さく併用
- 見出し下にアクセント色の一筆（draw-on）を1本
- FV 見出しのキーフレーズにマーカー、上に切り替わる言葉
- 「進め方」をレール／タイムラインで可視化（FV と PROCESS）
- カード・タグ・区切りの色ブロックでリズムを作る。波型区切り・手描き矢印の多用・意味のないグラデーション/抽象図形は使わない

動きは控えめに：マーカーやアンダーラインの描画、FV の言葉の切り替え、`prefers-reduced-motion` 対応。派手なアニメーションは見せない。

# 19. アニメーション

基本方針は、

「動いていることを見せる」のではなく、
「サイト体験を少し良くするために動かす」

とする。

## 避けるもの

- 派手なページトランジション
- 過剰なパララックス
- 大量のスクロールアニメーション
- 目的のない装飾アニメーション
- 技術力を見せるためだけの演出

## 使用する方向

- イラストの軽いループアニメーション
- UI要素の微細な動き
- スクロールに合わせた控えめな表示
- FVなど重要部分の自然な動き

---

# 20. 全体で伝えたいブランドイメージ

最終的にサイトを見た人に、

「この人なら、自分たちの案件でも丁寧に進めてくれそう」

と思ってもらうことを重視する。

伝えたい印象は、

- 丁寧
- 相談しやすい
- 一緒に考えてくれる
- 制作前に整理してくれる
- 認識を揃えて進めてくれる
- 制作だけでなく運用まで考えてくれる
- AIなども活用して効率的に進めている
- Web制作会社から案件を任せやすい
- 継続して相談できそう

というもの。

---

# 21. サイトで避ける方向性

以下のようなサイトにはしない。

- コーディングスキルだけをアピールするサイト
- 技術用語を大量に並べるサイト
- 実績画像だけを並べたギャラリー型ポートフォリオ
- 派手なアニメーションで技術力を見せるサイト
- かわいさに寄りすぎたデザイン
- 情報が少なく、雰囲気だけで判断させるサイト
- 「何でもできます」とだけ伝えるサイト
- 制作工程だけを説明するサイト

---

# 22. サイトを通して作りたい認識

訪問者に最終的に、

「Webサイトを作れる人」

ではなく、

「Webについて一緒に考えながら、設計・制作・運用まで任せられる人」

と認識してもらう。

さらに、

「制作会社の案件を安心して任せられる外部パートナー」

というポジションにつなげる。

# 26. 最終的なサイトの方向性

このサイトで目指すのは、

「Web制作の技術力を見せるポートフォリオ」

ではなく、

「この人にWebの仕事を相談・依頼したいと思ってもらうための営業サイト」

である。

そのため、

技術力
＋
事業理解
＋
課題整理
＋
設計力
＋
制作力
＋
コミュニケーション
＋
運用力
＋
AI活用

を一つのブランドとして見せる。

最終的には、

「事業理解、課題整理、改善提案、設計、制作、運用まで一気通貫で任せられる外部Web担当」

という認知につなげる。
